# Color — and the one rule for Bitcoin orange

_3 September 2026. Mehmet: "I love all the colors… but can I have Bitcoin
orange at places where it is rare but not possible to miss."_

Palette (app/field.css `:root`): void `#0A0B0F`, frost `#F4F7FA`, cobalt
`#4B6BFF`, mint `#42F5B6`, mist `#AAB2C0`, error `#FF6B6B`, and now
**btc `#F7931A`** with `--btc-soft` / `--btc-line`.

## The rule

Orange appears only where the thing on screen **is Bitcoin**: the price,
the block, paying in bitcoin. It is never a button, a link, a hover, a
kicker, or a decoration. Rare by rule, so the eye learns that orange means
the chain. Cobalt and mint keep meaning "the system" and "approved".

## Where it is used (keep this list honest)

- Bitcoin desk: the live dot, and the price value.
- Footer block clock: the live dot.
- Payments: the icon box on "Bitcoin payments engineering" (home and
  Offers), the "pay in bitcoin" note on Offers, the ₿ glyph on the BTCPay
  node in the payments illustration, the serif ticks on `LogoMarkBitcoin`.

Everything else stays cobalt/mint. Adding a new orange use means adding a
line here and asking whether the thing is actually Bitcoin.
