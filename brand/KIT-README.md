## Start here

- Website/design file: SVG in `01-marks` or `02-lockups`.
- Dark background: `gradient-transparent-dark` (light lettering).
- White/light background: `gradient-transparent-light` (dark lettering).
- Background baked in: `gradient-on-dark` or `gradient-on-light`.
- One-colour production: `mono-black` or `mono-white`. White artwork is invisible on a white preview; it is not an empty file.
- Profile: `04-avatars/maydalabs-avatar-dark-400.png`. Padding supports circular cropping.
- Website icons: `03-icons`. ICO contains 16, 32, 48 and 256px frames. Apple icon is opaque 180px PNG.
- Read `05-guidelines/maydalabs-solid-gate-usage.pdf` for spacing and application.

## Included

Transparent/opaque marks; horizontal, stacked and wordmark-only lockups; outlined SVGs; 2048px mark and 2400px lockup PNGs; favicons; 400/1024px avatars; usage PDF; overview; geometry/typography source; palette tokens; original licensed font/license; SHA-256 inventory.

SVG is the scalable master. PNGs are sRGB exports, not vector files. All logo text in lockup SVGs is outlined; fonts cannot substitute. The original variable font supports editable typesetting: weight 700, width 100, optical size 16.32, -0.03em tracking. Do not retype the exported lockup for routine use.

## Identity rules

Exact approved 32-unit geometry: 28-unit solid rounded tile, transparent converging inputs, vertical gate and output dot. Gradient runs horizontally cobalt to mint. Wordmark: MaydaLabs with raised multiplication sign, not a lowercase x.

Leave four master units outside the visible tile on every side (one seventh of its 28-unit width). Native SVG has only two units built-in: add remaining clearance in layout. Minimum symbol size 16px; prefer 24px+. At favicon size, use mark only. Recommended horizontal lockup minimum width 160px. Test actual output medium before printing.

Never stretch, rotate, outline, bevel, add a Bitcoin badge, close cutouts, arbitrarily recolour, or place transparent artwork on a busy photograph. Multiplier and mark are not separate sub-brands. MaydaOS remains private; this package does not change access. Satoshi Gazette and client identities are not included or transferred.

## Scope

Digital sRGB brand kit, not trademark clearance, certified colour proof or Pantone/CMYK specification. For speciality print or embroidery, have the printer test the monochrome vector. No profile uploads, publishing, accounts, messages or deployments are performed by delivering these files.
